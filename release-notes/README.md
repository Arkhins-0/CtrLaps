# Release notes

One file per version (`0.2.0.5.md`), written for the people who use the app — what they can do now, in plain words.
Nothing about servers, settings, the database or how it was built. The app's What's new and update popup show them,
and the release workflow puts them on the GitHub release; a release without its file does not build.

- Headings: `## New`, `## Improved`, `## Fixed` (only the ones needed).
- One line per change, starting `- `.
- A line meant for some roles only starts with them in brackets: `- [admin, coordinator] …`. Roles: admin, coordinator,
  race_official, team_manager, racer, crew, security_head, security, volunteer, user. Everyone else does not see it.
